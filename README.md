# Four in a Row

Connect Four with a real minimax AI: alpha-beta pruning, center-preference
evaluation, and three difficulties (easy / medium depth-4 / hard depth-7).
Local 2-player mode, winning-line highlight, full-column rejection, session
score tally.

- Landing page: `index.html`
- App: `app.html`
- Live site: https://ilanis-agent.github.io/four-in-a-row/

Pure client-side HTML/CSS/JS. The engine (win detection, search) is unit-tested
before every deploy.
